# 家庭菜单阅读页演示

用于验证手机及微信能否打开、阅读并展开菜谱。示例为2026-09-24晚餐、3人、3道菜，明确属于合成安排，不代表真实家庭菜单。未做烹饪实测。

仅包含静态页面和许可说明；没有APP安装包、完整菜库、账号令牌、家庭历史或私人备注。页面不需要登录，无访问控制，适合此公开演示，不应将真实家庭资料提交到本仓库。

HTML/CSS/JavaScript以可编辑源码形式提供，遵循GPL-3.0-or-later，许可证见LICENSE。页面由本项目在openCook试验中新增的阅读页生成器输出；上游：https://github.com/oliexdev/openCook ，固定版本 a50ad5a31d9fd6cf7bc7e65234c5794594891780 。这不是openCook官方站点。

三道示例菜的内容整理自HowToCook固定版本 c2063eb7050bac0cb998779c62fa08c649c9882f，原资料按Unlicense发布，原文见HowToCook.LICENSE；每道菜附有具体来源链接。不使用原站照片。

根目录的三道菜页面仍是手动发布的合成演示。`reader/` 是通用阅读器：APP 在本地把确认的一餐压缩到网址片段中，仓库不保存逐餐菜单。完整链接的持有人可以阅读、复制和转发；当前没有身份验证、撤回或到期能力，不能当作严格私密分享。

通用阅读器和 APP 发链接功能仍属试用，微信是否保留完整长链接、接收端浏览器能否解压及国内网络可达性须分别实测。免费托管的长期条件也不能由一次可访问推定。
